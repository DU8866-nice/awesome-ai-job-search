# 贡献指南 · Contributing

欢迎推荐项目、纠正错误或补充说明。English version below.

## 怎么提交

- **推荐项目**：[提交 Issue](https://github.com/DU8866-nice/awesome-ai-job-search/issues/new/choose)，写上仓库地址和一句话说明。
- **直接改**：编辑 [`data/tools.yaml`](data/tools.yaml)，把条目加到合适的分类里，然后提 PR。README 由 `scripts/build_readme.py` 生成，请不要直接改 README。

每个条目需要：

```yaml
- repo: owner/name
  zh: "一句话中文说明：它做什么、适合谁。"
  en: "One-sentence English description."
  agent: true      # 可选：在 Claude Code、Codex 等 AI 编程助手里运行
  selfhost: true   # 可选：本地运行或自己部署，数据在自己手里
  cn: true         # 可选：有中文界面或文档，或专为国内求职做
  auto: true       # 可选：会自动操作招聘网站（抓取或投递）
```

本地预览：

```bash
pip install pyyaml
GITHUB_TOKEN=你的token python scripts/update_stats.py   # 可选，刷新星标
python scripts/build_readme.py
```

## 收录标准

- GitHub 上的开源项目，和找职位、写简历、匹配职位、填表投递、跟踪进度或面试准备直接相关。
- 能实际使用：有可安装的版本、在线地址或清楚的使用说明。
- 说明要客观，写清楚数据存在哪里、会不会自动操作招聘网站。
- 一年以上没有更新会标 💤，已归档的标 📦，链接失效的会移除。
- 推荐自己的项目没问题，请在 Issue 或 PR 里说明。

不收录：

- 在面试或笔试中实时给答案的“隐身”作弊工具；
- 专门绕过验证码、反爬或平台风控的工具；
- 帮人编造学历、经历或证书的工具；
- 刷星、仿冒，或主要用来给付费服务导流的仓库。

## How to contribute

- **Suggest a project**: [open an issue](https://github.com/DU8866-nice/awesome-ai-job-search/issues/new/choose) with the repository URL and one sentence about it.
- **Edit directly**: add an entry to [`data/tools.yaml`](data/tools.yaml) in the right category and open a PR. The README is generated by `scripts/build_readme.py`; please don't edit it by hand.

## What gets listed

- Open-source projects on GitHub for finding jobs, building or tailoring resumes, filling applications, tracking progress or interview prep.
- Usable: an installable release, a live site or clear instructions.
- Plain descriptions that say where data is stored and whether the tool automates job sites.
- Projects with no update for over a year are marked 💤, archived ones 📦, and dead links are removed.
- Suggesting your own project is fine; please say so in the issue or PR.

Not listed: "stealth" tools that feed answers during live interviews or tests, tools built to bypass CAPTCHAs, anti-scraping or platform risk controls, tools that fabricate degrees, experience or certificates, and repositories with fake stars, impersonation or that mainly funnel to a paid service.
